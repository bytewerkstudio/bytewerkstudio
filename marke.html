Warum diese Form

Die Marke ist die Arbeit, reduziert.

Die meisten Logos sind Zeichnungen. Dieses ist eine Konstruktion: vier einzelne Körper, die nur zusammen Sinn ergeben. Nimmt man eines weg, ist das Zeichen unvollständig — genau wie ein Produkt.

Das Raster ist 28 mal 28 Einheiten. Jede Kachel ist 11,5 Einheiten breit, der Abstand beträgt 2, der Radius 3. Der Punkt liegt auf demselben Raster und ist minimal größer als eine Kachel (11,9 zu 11,5) — so wirkt er wie eine andere Art von Ding, nicht wie eine vierte Kachel.

Nichts ist Dekoration. Die Fase gibt es, damit die Formen Licht fangen wie Papier. Den Faden gibt es, damit die Teile einen Grund haben zusammenzubleiben. Und den einen Akzent gibt es, damit es genau eine Stelle gibt, an der man hinsieht.

Vier Regeln

Wie das Zeichen es selbst bleibt.

Kurz genug, um sie zu behalten, streng genug, damit elf Produkte wie ein Studio aussehen.

  1. Nie drehen oder verzerren

    Das Zeichen steht rechtwinklig zur Seite. In 3D darf es sich drehen, im Layout nicht.

  2. Ein Akzent, eine Stelle

    Ist der Punkt terrakotta, ist es sonst nichts auf der Fläche. Ist eine Fläche terrakotta, wird der Punkt papierweiß.

  3. Die Proportion halten

    Immer das ganze Zeichen skalieren, nie eine einzelne Kachel. Der Abstand macht es lesbar.

  4. Papier, nicht Plastik

    Kein Glanz, kein Neonlicht, kein Verlauf in den Formen. Das Licht kommt aus dem Material, nicht aus einem Effekt.

So geht es

  • Zeichen auf Papierweiß oder Tinte setzen
  • Mindestens eine Viertelkachel Schutzraum lassen
  • Den Punkt als einziges farbiges Element nutzen

So nicht

  • Eine einzelne Kachel umfärben
  • Schatten, Konturen oder Leuchten ergänzen
  • Aus vier einzelnen Bildern nachbauen
