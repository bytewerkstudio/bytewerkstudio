Das sind die echten Custom Properties der Vorschau. Sie lassen sich in jedes Stylesheet übernehmen.

Warum das kein Spielzeug ist

Eine Probe, die man behalten kann.

01

Echte Tokens, kein Bild

Die Vorschau ist HTML und CSS. Was du siehst, steht so im Code — Schrift, Abstände, Radien, Farben. Nichts ist nachträglich hineingemalt.

02

Kontrast wird gemessen

Jede Kombination wird beim Wählen gegen WCAG AA geprüft. Der Wert unter der Vorschau wird berechnet, nicht geschätzt.

03

Mitnehmen oder schicken

CSS kopieren, Link behalten oder die Auswahl als Briefing senden. Danach übernimmt das Studio — Umfang, Zeitrahmen, Budget.
