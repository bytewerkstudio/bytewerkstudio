Handwerk

Warum ein Raster aus Papier?

Weil eine Wortmarke mehr ist als eine Schrift auf einem Bildschirm. Sie muss als App-Icon funktionieren, auf dem Schild am Laden und im Kopf einer Rechnung — und in jeder Größe noch nach Absicht aussehen.

// Raster

Jede Platte sitzt im Raster

Ein festes 5 × 7-Raster hält die Wortmarke ruhig. Nichts verrutscht, in kleinen Größen muss nichts nachjustiert werden — derselbe Grund, aus dem der Buchdruck mit echten Lettern arbeitete.

// Licht

Licht statt Effekte

Eine warme Key-Lampe, eine weiche Füllung, ein kühler Rand. Kein Bloom, kein Neon. Die Tiefe entsteht aus der Fase und den Seitenflächen der Platten — nicht aus einem Filter.

// Ohne Netz

Keine fremden Server

three.js liegt lokal im Repository, keine Schrift wird von Dritten geladen, nichts wird mitgeschnitten. Ohne WebGL bleibt die Wortmarke als echter Text auf der Seite stehen.
