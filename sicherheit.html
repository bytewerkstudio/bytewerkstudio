Weglassen

Was diese Seite nicht tut.

Die meiste Angriffsfläche ist freiwillig. Sie wurde bewusst weggelassen.

01

Kein Tracking

Keine Analyse, keine Pixel, keine Werbenetzwerke, kein Fingerprinting. Gemessen wird in der Traffic-Ansicht von GitHub Pages — aggregiert und ohne Personenbezug.

02

Kein Fremdcode

Jedes Skript kommt von dieser Domain. Es gibt kein CDN, keinen Tag-Manager und kein eingebettetes Widget, das sich ohne Commit ändern könnte.

03

Kein Server, keine Formularposts

Das Kontaktformular öffnet dein Mailprogramm. Es gibt keinen POST-Endpunkt, keine Datenbank auf diesem Host und keinen Upload. Nichts davon wird an die Seite gesendet.

04

Keine Schriften von anderen Servern

Inter, Newsreader, Space Grotesk, Manrope und JetBrains Mono liegen auf dieser Domain. Keine Anfrage geht an Google Fonts, also auch keine IP-Adresse.

Richtlinie

Wie sie geschützt ist.

Die Content-Security-Policy wird als Meta-Tag ausgeliefert, weil GitHub Pages keine eigenen Header erlaubt. Jede Zeile unten wird vom Browser durchgesetzt.

Direktive Wirkung Zustand
script-src 'self' 'sha256-…' Nur eigene Skripte und die exakt gehashten Inline-Blöcke. Kein unsafe-inline. aktiv
style-src 'self' Kein einziges Style-Attribut erlaubt. Die 203 Attribute aus dem Markup liegen jetzt als Utility-Klassen in styles-inline.css. aktiv
object-src 'none' Keine Plugins, keine Alt-Embeds, keine PDF-Objekte. aktiv
frame-src 'none' Die Seite kann keine fremden Frames einbetten. aktiv
base-uri 'self' Ein eingeschleustes base-Tag kann relative URLs nicht umleiten. aktiv
form-action 'self' mailto: Formulare dürfen nur an diese Origin senden oder ein Mailprogramm öffnen. aktiv
connect-src 'self' Kein fetch oder XHR zu fremden Hosts. Wer Supabase aktiviert, trägt dessen Origin zuerst ein. aktiv
font-src 'self' Schriften liegen lokal. Der Browser kann keine Schrift von einem anderen Server laden. aktiv
img-src 'self' data: Bilder nur von dieser Domain; data-URIs sind für erzeugte Texturen erlaubt. aktiv
upgrade-insecure-requests Jede versehentliche http-Anfrage wird auf https gehoben. aktiv
Referrer-Policy strict-origin-when-cross-origin: volle Pfade bleiben auf dieser Seite. aktiv
Rahmen-Schutz Ein kleines Boot-Skript verweigert fremde Rahmen und blendet den Inhalt aus, wenn das oberste Fenster nicht geändert werden kann. aktiv
